# MVP product requirements

## Purpose

Provide a lightweight live-search interface that makes calls for papers, journal submissions, and book chapters easier to find across selected scholarly and announcement sources.

## Primary interaction

1. Select one or more Objects of Study.
2. Select one or more call types.
3. Execute a live search.
4. Review normalized result cards.
5. Open the source page in a new tab.

## Scope

The initial vocabulary emphasizes media, communication, games, visual communication design, education, art, and adjacent areas. Searches outside that area are not blocked, but coverage is explicitly limited.

## Exclusions

- Persistent CFP dataset
- Deadline verification
- Automated full-page extraction
- Accounts and saved searches
- Email alerts
- Paid search services
- Editorial dashboard
